# TEXporter for MuseScore: logo

<img src="../plugin/assets/tex-logo.png" alt="TEXporter for MuseScore logo" width="160">

Product: **TEXporter**. Edition: **TEXporter for MuseScore**. Short name: **TEX**. The edition label distinguishes this plugin from possible future adapters; the logo lettering stays TEX.

The current logo keeps the TEX lettering, musical pulse and export arrow from the original design, with a flat matte finish and a purple-to-blue color gradient. Bevels, shine and glow were removed. Skyeler Robinson's SR Percussion logo was a reference for the colors and flat graphic style; its SR lettering was not reused.

The source project's `branding/tex-logo.png` is the current master. The identical runtime asset is `../plugin/assets/tex-logo.png` relative to this source document. Distribution/install copies of this document reference the bundled `../assets/tex-logo.png` instead. Both preserve the generated alpha transparency outside the navy badge. The master is suitable for a repository avatar or release artwork; the plugin displays the runtime copy in its header. The original glossy logo and generation notes are retained privately as local archives and excluded from the repository.

Originally generated with the built-in image generation tool on 2026-10-03. The original prompt was:

```text
Use case: logo-brand.
Asset type: final square logo PNG for a MuseScore music-to-metronome export plugin and GitHub avatar.
Primary request: create an original, professional logo for TEXporter, short name TEX, by Skyeler Robinson. Exact logo text is "TEX"; spell T E X correctly and make all three letters immediately readable.
Style reference described: SR Percussion uses angular geometric typography, fine neon-like parallel contours and saturated purple-to-electric-blue gradients on deep navy. Borrow only the color mood and clean technical style. Create a different silhouette and different letter construction, not the SR monogram.
Design: a bold, compact custom TEX wordmark with a subtle musical pulse and forward/export motion integrated into the X. The E must retain all three horizontal strokes. Distinct angular geometry, moderately thick strokes and limited parallel outline detail so it reads at icon scale. Purple on the left transitioning to cobalt/electric blue on the right, crisp controlled luminous edges. A deep navy rounded-square badge can sit behind the mark for reliable contrast in both light and dark apps; area outside the badge is transparent. Balanced centered composition with generous margins, no cropped strokes.
Text (verbatim): "TEX". No other text, no tagline, no SR, no PERCUSSION, no MuseScore or TonalEnergy logos, no watermark, no mockup, no 3D perspective, no thin illegible circuitry or noisy glow. Produce one finished logo only with actual alpha transparency outside the rounded-square badge.
```

## Flat matte edit

Edited with the built-in image generation tool on 2026-10-03. The previous TEX logo was the edit target; SR Percussion was a style reference only. No manual image editing or resizing was performed. The exact edit prompt was:

```text
Use case: style-transfer / precise-object-edit.
Image 1 is the edit target: existing TEXporter TEX logo. Image 2 is a style reference only: Skyeler Robinson's SR Percussion logo.
Make Image 1 the same logo with a flatter, matte graphic finish. Preserve the TEX lettering, all three E strokes, exact letter silhouettes and negative spaces, the pulse crossing the X, the right-facing export arrow, dark navy rounded-square badge, centered composition, blue/purple palette and transparent area outside the badge.
Remove every bevel, extrusion, metallic effect, glossy highlight, edge lighting, bloom, glow, reflected shine, grain and lighting gradient. Convert the existing shapes into crisp, clean, flat 2D color shapes with consistent contour widths. A restrained purple-on-left to blue-on-right color gradient is allowed, but it must read as ink color rather than shine or depth. Use a quiet matte dark navy badge, no vignette or spotlight. The finish should look like a deliberately drawn flat vector logo, close to the calm printed graphic quality of Image 2.
Do not redesign, rearrange, replace or add letters or symbols. Do not copy Image 2's SR monogram or PERCUSSION text. Exact text remains "TEX" only. No extra text, no watermark, no mockup, no perspective, no drop shadow. Preserve actual alpha transparency outside the badge and return one finished logo.
```
